ŹRÓDŁO NIEPOTWIERDZONE
!
Nie podłączono jeszcze wiarygodnego strumienia danych E4K PL1

Nie będziemy pokazywać fikcyjnych ataków, statusów aktywności ani strat honoru. GGE Tracker nie zawiera naszego świata, dlatego został usunięty z portalu jako źródło danych. Nadal szukamy wiarygodnego źródła obsługującego dokładnie mobilny świat E4K PL1. Zewnętrzne mosty do API gry mogą wymagać danych logowania operatora, więc nie będziemy przesyłać tam Twojego hasła.
